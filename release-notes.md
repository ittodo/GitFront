# GitFront Preview 0.0.2

- Add current branch, selected ref, and all-ref commit history scopes.
- Add combined commit message, author, email, SHA, and path filtering.
- Build a lightweight SQLite search index progressively without copying the Git graph.
- Show local and remote branches containing a commit on hover and in commit details.
- Add configurable history-cache limits, cache cleanup, and targeted history invalidation.
- Watch linked-worktree Git directories and preserve the virtualized 200-commit paging model.
